# SC55DisplayDot
Old scripts for creating DisplayDot SysEx for the Roland SC-55.
> NOTE: Some of them are currently broken. You will need to troubleshoot to get these working. A requirements file has been included. Install it with `pip install -r requirements.txt`. You will also need Python.

> COMPATIBILITY NOTE: I believe this works on other Sound Canvas devices too. But I cannot confirm this.

As seen [in my YouTube video](https://youtu.be/t9PnQ0bqCa0), and on [88EmuPlayer](https://theusualsuspects.io/downloads/88emuplayer)!

This repo contains various scripts I made with help from ChatGPT back in 2025, along with support from [vgthecoder](https://github.com/vgthecoder).

I swear this took forever; Roland's documentation is quite poor for DisplayDot. Even with the use of AI, it took a few days to even understand what SysEx, and checksums were used. Blegh
